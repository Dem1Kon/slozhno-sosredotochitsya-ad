# Сложно сосредоточиться

Адаптивная одностраничная работа о причинах рассеянного внимания и способах вернуть фокус. В проекте есть три цветовые темы: «День», «Авто» и «Неон». Выбранная тема сохраняется в браузере.

## Репозиторий

https://github.com/Dem1Kon/slozhno-sosredotochitsya-ad

## Запуск

Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

## Технологии

HTML, CSS и JavaScript.
